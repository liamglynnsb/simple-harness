name: release-notes-format
description: Use when the user asks you to write release notes, a changelog entry, or a "what's new" summary for a software release.
---
Write release notes in this exact layout:

1. One summary line, in the past tense, on the first line.
2. A blank line.
3. Bullet points grouped under the headings Added, Changed and Fixed, in that order.
4. Leave out any heading that has no bullets.
5. Start every bullet with a past-tense verb, such as "Added", "Renamed" or "Fixed".
6. Use no other headings and write nothing after the last bullet.
