name: verify-arithmetic
description: Use whenever the user's request involves calculating a number with arithmetic.
---
Every time you compute a result with the calculator tool, check it before you answer.

1. After you get the result, run the inverse operation with the calculator. For
   multiplication, divide the result by one of the factors. For division, multiply
   back. For addition, subtract. For subtraction, add.
2. If the inverse gives you the original number, the result is verified. If it does
   not, say "mismatch" and report both numbers.
3. Report the answer in this form: expression = result (verified)

Never skip the check, even for simple sums.
